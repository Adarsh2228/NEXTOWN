
# 🚀 NEXTOWN – A Local Business Marketplace

NEXTOWN is a MERN-stack-powered digital marketplace platform built to help local small and medium-sized businesses go online with ease. It provides vendors with an intuitive dashboard, smart analytics, and tools to connect with customers, promote their offerings, and grow digitally.

---

## 📚 Project Overview

In an age dominated by large eCommerce giants, many local vendors struggle to create and manage their online presence. NEXTOWN bridges this gap by offering:

- 🛒 Vendor storefronts for product/service listings
- 💬 Real-time Q&A and chatbot interaction
- 📈 Analytics dashboard with business performance insights
- 🧠 AI-powered predictions to plan future sales
- 🌐 Community-focused "shop local" ecosystem

## 🏁 Getting Started

### 📦 Prerequisites

Make sure the following are installed:

- Node.js & npm
- MongoDB (local or cloud)
- Python 3.x
- Flask (for ML service)

---

### 💻 Running the Project

Open **two terminal windows** to start both the frontend and backend servers.

#### Terminal 1: Frontend

```bash
cd frontend
npm install
npm start
```

Frontend runs at: `http://localhost:3000`

#### Terminal 2: Backend

```bash
cd backend
npm install
nodemon server.js
```

Backend runs at: `http://localhost:5000`

> ⚠️ Ensure MongoDB is running and `.env` is correctly configured with the database URI.
